# きょうの料理ビギナーズ

## 仙台風いも煮

感想
- 食べ終わって残った汁はかなり濃い味になっている。
- 生のさといもと冷凍のさといもじゃ食感が全然違う。生のさといもを使うしかない。
  
材料
- 粗むきさといも1袋 250g
- 木綿豆腐1個 150g
- 追いがつおつゆ2倍 100ml
- 水 300ml
- 料理酒 大さじ2
- みそ 60g (箸の先に乗る一掬いで良しとする)

手順
1. さといもの皮を取って鍋に入れる。
2. 木綿豆腐を切らずに鍋の中央に入れる。
3. 追いがつおつゆ2倍100mlと水300mlの合計400mlを鍋に入れる。
4. 沸騰維持程度の火力で蓋をしないで10分煮る。
5. 鍋の中で木綿豆腐を6等分してさといもと混ぜて場所を交換する。
6. 沸騰維持程度の火力で蓋をしないで10分煮る。(合計20分)
7. 料理酒とみそを混ぜて器に入れる。
8. 火を止めて鍋から器によそう。
